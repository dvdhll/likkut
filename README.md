# רשימת ליקוט · משנת יוסף (לא רשמי)

אפליקציה שמתחברת לחשבון [משנת יוסף](https://mishnatyosef.org) שלכם, מושכת את ההזמנה הקרובה לאיסוף, וממירה אותה ל**רשימת תיוג נוחה לליקוט** — ממוינת לפי קטגוריות, עם תמיכה במיזוג כמה חשבונות (למשל שני בני משפחה) לרשימה אחת.

🔗 **שימוש:** [https://likkut.pages.dev](https://likkut.pages.dev)

---

## 🔒 שקיפות ואבטחה — הסיבה שהקוד פתוח

האפליקציה היא **100% צד-לקוח (client-side)**. אין שרת, אין בסיס נתונים, אין שום מקום שאוסף מידע. כל הקוד נמצא בקובץ אחד: [`public/index.html`](public/index.html) — אתם מוזמנים לקרוא אותו.

מה זה אומר בפועל:

- **הסיסמה** נשלחת **ישירות מהדפדפן שלכם** ל-`v2.mishnatyosef.org` (בדיוק כמו באתר הרשמי), ו**אינה עוברת בשום שרת אחר**. המפתח לא רואה אותה ולא שומר אותה — אף פעם.
- **אסימון הגישה (token)** שמתקבל אחרי ההתחברות נשמר **רק ב-`localStorage` של הדפדפן שלכם**. הוא לא נשלח לשום מקום חוץ ממשנת יוסף.
- **אין שרת מאחורי האפליקציה** — רק קובץ HTML/JS סטטי שמתארח על Cloudflare Pages. אין מאגר טוקנים או סיסמאות שיכול לדלוף.
- האפליקציה **קוראת רק את רשימת המוצרים ופרטי האיסוף**. היא אינה נוגעת בפרטי אמצעי תשלום או בפרטים אישיים אחרים, גם כשהם מופיעים בתשובת ה-API.

איך לוודא בעצמכם: פתחו את [`public/index.html`](public/index.html), חפשו את כל הקריאות ל-`fetch(` — תראו שכולן הולכות אך ורק אל `https://v2.mishnatyosef.org/api/...`, ולשום כתובת אחרת.

**חריג יחיד — סטטיסטיקות שימוש:** הדף טוען beacon של [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) (`static.cloudflareinsights.com`) שסופר **כניסות ומבקרים בלבד**, באופן **מצטבר ואנונימי, ללא עוגיות וללא מידע אישי**. הוא אינו נוגע בפרטי ההתחברות, בטוקן או בהזמנות. זו הקריאה החיצונית היחידה מלבד ל-API של משנת יוסף.

## איך זה עובד

1. אתם מתחברים פעם אחת עם המייל והסיסמה של משנת יוסף.
2. הדפדפן מקבל token (תקף 30 יום, מתחדש אוטומטית) ושומר אותו מקומית.
3. בכל כניסה: הדפדפן מושך את ההזמנה הקרובה לאיסוף, ממיין לקטגוריות, ומציג רשימת תיוג. סימוני "נלקט" נשמרים מקומית.
4. אפשר לחבר כמה חשבונות — ההזמנות ממוזגות לרשימה אחת, עם ציון לאיזה חשבון שייך כל פריט.

## התקנה למסך הבית (PWA)

היישום ניתן להתקנה כאפליקציה למסך הבית (אנדרואיד / iOS / דסקטופ). האפליקציה עצמה מציגה הנחיות התקנה מותאמות למכשיר. מבחינה טכנית זו PWA: [`manifest.json`](public/manifest.json), service worker ([`sw.js`](public/sw.js)) שמאחסן את קובץ ה-HTML הסטטי לפתיחה מהירה/לא-מקוונת, ואייקונים ([`icon.svg`](public/icon.svg)).

## הרצה מקומית

זהו קובץ סטטי בודד. אפשר פשוט לפתוח את `public/index.html` בדפדפן, או:

```bash
npx wrangler pages dev public
```

פריסה (Cloudflare Pages):

```bash
npx wrangler pages deploy
```
